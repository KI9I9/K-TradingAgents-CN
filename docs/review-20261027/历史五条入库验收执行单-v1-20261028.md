## 失败处理

Mongo 单文档更新原子，但这 5 条有序 bulk 不构成跨文档事务。中途失败可能留下部分前缀。

- 驱动与写入目录均一次性创建，禁止自动重复执行；PyMongo `retryWrites=False`。
- 任何异常或结果不确定都停止，保留目录、备份、ObjectId 清单和已写入记录。不因 SSH 查询失败再次启动。
- **不自动回滚或删除记录**，避免删除并发数据。若失败，先按本次 ObjectId 与 payload 核验残留，再准备精确处理方案；不能整表恢复或覆盖其它来源。
- 成功后核验其它 Tushare 记录的完整 BSON 哈希仍与备份相同，所有受保护闸门文件未变。
