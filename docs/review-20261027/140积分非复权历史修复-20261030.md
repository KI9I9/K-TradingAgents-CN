# 140 积分：非复权历史同步

用户已选择维持 140 积分，继续全 A 股历史按钮修复。官方权限表 doc_id=290：基础日线 50 次/分钟、8000 次/日；adj_factor 文档 doc_id=28 要求至少 2000 积分。此前 60/12000 的本地预算不匹配账户，不能将 adj_factor 偶发成功视为权限证据。

## 实现

- schema=2 许可仅 daily、每股一次，分钟最多 40、每日最多 7500；新预算 30000，沿用 Nov 3 14:00 CST 截止。其余程序使用同一账号仍会消耗平台额度，500 次余量不能保证其他客户端不超额。
- 新集合 `stock_daily_quotes_unadjusted`，沿用唯一键但物理隔离。`daily / none / lot / CNY` 契约；原表、前复权及旧 300613 不迁移、不覆盖。
- 原调度按钮按许可选择非复权流程，任务进度明确标注非复权；同日完整重放只对账。
- 显式读取：鉴权 `GET /api/stock-sync/history-unadjusted/{symbol}?limit=120`。无网络回退；返回口径、单位和升序记录。分析及现有 K 线默认路径仍用原来源，不会悄悄切换为未复权序列。需要非复权的调用方应显式选择新服务查询参数或此 API。
- 旧 qfq generation 必须已 STOP 且明确收到 usage_limit/insufficient_points 拒绝，才能显式退休。全部已保存结果核对；pending/fetching 与原 inventory 指纹逐一相同。未知网络结果、任何库漂移均拒绝。旧文件逐字节不改，quota 计数继承，不清零。
- 上游阻断后再次点击显示真实 reason，不再先被通用 disabled 遮住。

## 交付

`build_history_basic_bundle.py` 冻结九个已挂载文件；`prepare_history_basic.py` 校验 compose 差异、运行容器与保护文件；`run_history_basic_switch.py` 沿用已有停机、备份、验收失败回滚协议。39→39，不动镜像、前端与封印配置。

`inspect_history_basic.py` 采集即时股票池/原历史哈希。`run_history_basic_opening.py` 单次执行：备份所有旧 Tushare BSON 与索引，确认新集合不存在后创建唯一索引，逐项核对退休旧 generation，再经正常鉴权原按钮提交全市场。操作预留目录防止重复；失败停止、保留证据，不自动删除数据。

本文件是实现说明，**不代表生产已上线或全市场同步完成**；生产结果另记。全市场按逐股请求约 140 分钟下限，加上网络、落库和对账会更久。数据为最近窗口的历史日线，未恢复实时行情、ETF 或模拟交易。
