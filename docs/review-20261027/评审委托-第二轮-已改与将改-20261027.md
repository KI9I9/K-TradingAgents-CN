### 5.1 消费侧护栏（`app/routers/paper.py`，本次新增，10~40 行）

**动机**：上游无论如何都可能出问题（限频、休市、字段变更）。当前消费侧**不校验 `trade_date`、不校验时效**，只要 `high>0 and low>0` 就用——这是「静默用错价成交」的唯一入口。护栏把它降级为「明确拒绝下单」。

**拟定改动（A 股/ETF 分支）**：

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo
from app.core.config import settings

QUOTE_MAX_AGE_MINUTES = 30
QUOTE_CLOCK_SKEW_SECONDS = 300

def _local_now() -> datetime:
    return datetime.now(ZoneInfo(settings.TIMEZONE))

def _is_today_trade_date(value: Any, now: datetime) -> bool:
    s = str(value or "").strip()
    return bool(s) and s in {now.strftime("%Y-%m-%d"), now.strftime("%Y%m%d")}

def _quote_is_usable(q: Dict[str, Any], now: datetime) -> bool:
    if not _is_today_trade_date(q.get("trade_date"), now):
        return False                     # 非当日 → 视为无区间
    upd = q.get("updated_at")
    if isinstance(upd, datetime):
        if upd.tzinfo is None:            # pymongo 返回 naive UTC
            upd = upd.replace(tzinfo=timezone.utc)
        age = (now - upd.astimezone(now.tzinfo)).total_seconds()
        if age > QUOTE_MAX_AGE_MINUTES * 60:
            return False                  # 过期
        if age < -QUOTE_CLOCK_SKEW_SECONDS:
            return False                  # 未来时间（时钟异常）
    return True
```
