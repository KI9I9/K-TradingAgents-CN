## 7. 回滚

**原则：重建之前先证明「重启后不会自动恢复写入」，否则保持实例停止。**

```bash
# R0-a 证据
cat $D/prefs-before.json
```
- 两条都 `enabled=false`（或不存在）→ 直接 R1。
- 任一 `enabled=true`：
  1. 实例**仍运行**时先用 API `pause` 并确认 `paused=true`；
  2. 重读 `scheduler_preferences` 确认落库；
  3. 再走 R1/R2。**不允许**「先重建、再靠 pause 救」。

```bash
# R1 还原 3 个已有挂载源
sudo cp $B/config.py $SRC_CFG
sudo cp $B/provider-akshare.py $SRC_PROV
sudo cp $B/akshare_sync_service.py $SRC_SYNC

# R2 去掉新增挂载重建（必须在 R1 之后，否则 ModuleNotFoundError）
CHAIN=$(cat $D/chain-before.txt)
sudo docker compose --project-directory $PD --project-name ta-live-088a60b962bf --profile cutover-approved \
  $(printf ' -f %s' $(echo "$CHAIN" | tr ',' ' ')) \
  up -d --no-deps --force-recreate backend

# R3 复验
sudo docker inspect $C --format '{{len .Mounts}}'                 # 21
sudo docker exec $C sha256sum /app/app/worker/akshare_sync_service.py /app/app/routers/stock_sync.py
(cd $B && sudo sha256sum -c SHA256SUMS)                            # 3 个源回到备份值
# 任务仍 paused（或按 R0 结论明确记录）

# R4 前端回滚（原链，不带 frontend-dist）
CHAIN=$(cat $D/chain-before.txt)
sudo docker compose --project-directory $PD --project-name ta-live-088a60b962bf --profile cutover-approved \
  $(printf ' -f %s' $(echo "$CHAIN" | tr ',' ' ')) \
  up -d --no-deps --force-recreate frontend
sudo docker inspect $F --format '{{len .Mounts}}'                  # 4
```

**故障分支（backend 起不来 / API 不通）**：`sudo docker stop $C` → `sudo docker inspect -f '{{.State.Running}}' $C` 必须为 `false`
（不要用宿主机 `ss` 推断容器内进程）→ 走 R1/R2 → 重建后再查一次偏好与 `paused`；仍为 true 则立即停机上报，不自行改库。
