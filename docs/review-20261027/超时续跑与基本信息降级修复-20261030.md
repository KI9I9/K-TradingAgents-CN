## 实现

- `BatchJob.perform` 仅对 schema 2 的 daily 超时最多重试两次，退避 2/4 秒；失败请求仍扣额度且留下不可覆盖的证据。权限、限额、响应校验错误不重试。
- `recover_raw_timeout` 是运维动作，无 HTTP 重置接口；持有准入锁、工作区锁、写闸锁，检查原计划/779 次计数/唯一 fetching 项、核对所有已完成 payload 与未完成库存。只恢复该失败项，保留原计划及预算；持久化恢复证据后最后解除本代 STOP。中断不自动重试。
- `Workspace.status` 保留空结果/修订结果信息，失败进度不再把空结果算成成功；正常进度不被“跳过名单”覆盖。
- 基本信息完成结果缺外部名单或每日指标时标记 `success_with_errors + degraded`，保留已有指标；读旧记录时也纠正展示但不改写历史审计。降级结果不当作最近成功外部同步。
- 前端使用友好源名与持续可见的警告，不再弹出内部源标识作为正常完成提示。
