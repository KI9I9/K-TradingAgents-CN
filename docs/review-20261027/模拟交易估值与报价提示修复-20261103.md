# 模拟交易估值与报价提示修复（2026-11-03）

## 行为

缺少有效参考价的非空持仓返回 `market_value=null`、`unrealized_pnl=null`。
对应币种的持仓市值及总资产也返回 null，并提供缺价数量和已知部分市值。
其他币种、现金及已实现盈亏保持原有口径。零持仓仍为零，不用成本价冒充行情。

持仓估值读取展示通道，不消耗按需成交报价额度。模拟交易页和首页显示“待估值”，
有参考价时展示来源、交易日和数据更新时间；数据更新时间不标成上游行情时间。

下单报价预览使用严格通道，保留停牌、非连续交易时段、超时、许可到期等原因，
通过公开白名单映射为中文。未知异常不透出上游异常内容。预览请求切换证券时
清空旧状态，并拒绝较早请求覆盖较新请求的结果。下单仍由服务端重新校验。
