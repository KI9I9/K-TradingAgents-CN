## 3. 这次到底改了什么（按问题域，不按提交顺序）

### 3.1 供给侧：不再写「看起来新鲜」的假数据

- **写入总闸** `QUOTES_WRITE_ENABLED`，默认**关闭**。已接 5 个写入点：
  `akshare_sync_service`（批量/单只/回退）、`stock_sync._sync_latest_to_market_quotes`、
  `quotes_ingestion_service._bulk_upsert`、`stock_data_service.update_market_quotes`、`qmt_sync_service`。
- **时间闸门**：非交易日、日历来源为 `fallback`、09:30 前、15:30 后 → 整轮跳过。
- **采集时刻整批固定**：`captured_at` 在拿到快照那一刻记，写库不得重新起算；`updated_at` 才是写入时间。
- **不完整快照整条拒写**（close/high/low 必须齐全且 `low ≤ close ≤ high`），失败不刷新时间戳。
- **通道切换 `$unset` 旧 `quote_time`**（`$set` 删不掉字段）。
- 空标的池、全部拒写 → `success=False`；单股回退按「实际被接受」判成功。

### 3.2 消费侧：拿不到证据就不成交

`app/services/quote_contract.py` 是唯一判定出口：

| 检查 | 现状 |
|---|---|
| 交易日 == 今日 | 必须 |
| 交易状态 | 必须 `trading/交易中/正常…`；未知即拒 |
| 上游行情时间 | ≤30 分钟，未来漂移 ≤60 秒 |
| 无行情时间时 | 明示为「快照」：仅 09:30–15:30，年龄 ≤ 声明周期+120s（上限 40 分钟） |
| 日线回退 | ≥15:05 + 写入时间 ≥15:00 + 不在未来 + **必须 `is_final`/`final_state`** + 交易状态 |
| 定价依据 | 与成交**同一条记录**产出（`*_and_basis`），不再二次查库 |

展示路径（持仓估值）与成交路径已分离：展示不限时效、逐级回退，basis 标 `channel=display` 且提示「不可用于成交」。
