## 实地核验发现并修正的工具问题

生产 `docker compose config --format json` 会把 `bind.create_host_path=false` 省略，输出 `bind:{}`。
执行了仅解析配置的三组探针：false/空对象均输出 `{}`；true 输出 `{"create_host_path":true}`。
未创建探针容器、未拉取镜像、未访问挂载源。校验器现接受两种等价的 false 表示，仍拒绝 true 及其他挂载选项。
发布 override 中仍显式写 false；没有通过删除保护字段来绕过检查。

新增 `deploy/query_quote_guard_jobs.py`：读取权限 600 的 JWT 文件或两行用户名/密码文件，
通过 SSH stdin 传给生产容器，只调用正常登录接口（凭据模式）及 GET 调度 API。
输出仅保留目标任务状态；不打印、不落盘、不放到命令行中的密码/Token；不使用 JWT_SECRET 自签。
登录会建立正常认证会话及审计记录，不应称为零写入。查询不修改行情、交易记录或任务偏好。
拒绝跳转和代理，固定请求容器内 loopback，避免凭据被转发。

相关测试新增 8 项，累计 **175 项**（86 + 11 + 6 + 17 + 14 + 9 + 25 + 7）。
真实生产 API 尚需有效凭据；工具离线测试不代表已通过生产鉴权。

并行收到 `72a8b16` 的 Token 补充文档，同时该提交误撤了 v9 作废提示。
