## 0. 必须先读：这次部署后「不能交易」

| 闸门 | 默认值 | 后果 |
|---|---|---|
| `QUOTES_WRITE_ENABLED` | **关闭**（`prepare_quote_write` 统一拦截） | 定时、手动（收藏/个股同步）、单只、批量**全部写不进行情表** |
| `trading_status` | **必须显式「交易中」** | 现有记录没有该字段 → 所有成交被拒（`trading_status_missing`） |
| 日线最终性 | **必须 `is_final=true` 或 `final_state=closed`** | 现有日线没有该字段 → 日线通道关闭（`bar_finality_unproven`） |

结论：**本次部署的结果是「停止错误成交、停止错误写入」**，不是「恢复模拟交易」。
要恢复，必须按顺序单独批准：① 打开写入总闸 → ② 接交易状态来源 → ③ 接日线最终性证据 → ④ 启用任务。
任一步都不能用「先上线再说」跳过。
