## 回滚和异常

正常失败或未提交的 worker 被终止后，撤除的只能是与本次哈希完全相同的新增文件/链接。
原 unit、许可和数据库不恢复、不覆盖、不删除。重新加载 systemd、重启原中继后，
核对旧目标、原保护文件及 socket inode，状态应为 rolled_back。

若候选/链接被第三方改变或原控制文件漂移，保留现场并停止本 Tushare socket/service，
状态为 rollback_incomplete_transport_closed，必须人工核查，不能覆盖未知内容。
到期后回滚也保持传输关闭。原 SSH 链路本就不可靠，回滚只证明配置恢复，不能保证 TLS。

守护器能处理 SSH 断线、worker 超时/被杀及 --collect 后 unit 已不存在的情况；迟到守护器
不能撤回 committed 的路线。临时回滚 timer 不跨整机重启保留；未提交期间若主机重启，
先读现场，禁止继续恢复业务。持久到期 timer 和 ExecCondition 仍约束直连有效期。
