## 具体执行及退出条件

1. 在私有新目录备份本机unit/所有drop-in/ssh_config与生产sshd配置（不复制私钥）；保存清单、权限、哈希及原有效选项。确认STOP、计数2298、原计划、没有运行中的历史任务；状态漂移即停。
2. 生产以当前sshd_config为基础创建独立进程参数；用`sshd -t`和`sshd -T -C user=ta-tushare-in,...`核验后才允许启动。参数固定为：

   ```text
   /usr/sbin/sshd -D -e -f /etc/ssh/sshd_config
   -p 443 -o AddressFamily=inet -o ListenAddress=0.0.0.0:443
   -o PidFile=/run/ta-tushare-ssh443-trial.pid
   -o AllowUsers=ta-tushare-in -o AuthenticationMethods=publickey
   -o PubkeyAuthentication=yes -o PasswordAuthentication=no
   -o KbdInteractiveAuthentication=no -o HostbasedAuthentication=no
   -o ForceCommand=/usr/sbin/nologin -o MaxSessions=0
   -o PermitTTY=no -o X11Forwarding=no -o AllowAgentForwarding=no
   -o PermitTunnel=no -o AllowStreamLocalForwarding=no
   -o AllowTcpForwarding=remote -o GatewayPorts=no
   -o PermitOpen=none -o PermitListen=127.0.0.1:32879
   -o ClientAliveInterval=30 -o ClientAliveCountMax=3
   ```

   有效配置必须只监听IPv4的443、AllowUsers必须仅有ta-tushare-in；若原配置的累加选项导致多监听或多账户，**拒绝启动**，不能照抄命令继续。保留既有host key及该账户authorized_keys限制，不改其内容。不得reload原sshd。
3. 使用独立transient systemd unit启动，`RuntimeMaxSec=600`、`KillMode=control-group`、不enable；检查时间仍早于原2026-11-03 14:00 CST期限。先验证只允许原账户/公钥认证。客户端严格使用原known_hosts，`HostKeyAlias=217.142.241.226`，先验证其在原专用known_hosts中确实存在；不得写入新主机密钥、使用accept-new或跳过验证。
4. 初次认证检查用`ClearAllForwardings=yes`、`-N`，不占用32879。若失败，不停现有转发，直接清理生产试验unit。
5. 仅在认证成功后切现有转发。先安装本机独立8分钟自动回退timer：回退脚本只在临时drop-in哈希仍等于本次候选时删除它，daemon-reload后恢复原服务；哈希变化则保留现场并报错。自动回退须先通过有效性检查、已启动，才可变更连接。
6. 本机使用独占创建的`/run/systemd/system/ta-tushare-forward.service.d/443-trial.conf`临时覆盖ExecStart为`/usr/bin/ssh -F /etc/ta-tushare-egress/ssh_config -p 443 -o HostKeyAlias=217.142.241.226 -N osaka-tushare-egress`，连接选项必须放在主机别名之前。先`ssh -G`逐项比较：除port/hostkeyalias外不得变化，固定RemoteForward、严格密钥校验及到期ExecCondition必须保留。停止原转发、应用临时配置并启动；不得同时创建两个竞争32879的客户端。
7. 检查生产32879监听归属新443会话后，按30秒上限至少5次验证真实UnixTLS路径，间隔5秒，证书/主机名检查不变；随后对固定上游`GET /`读取有上限的小响应（不带token、不调用dataapi），验证完整TLS及响应传输。记录耗时、错误、TCP重传。没有稳定改善就失败，不以systemd active或一次握手成功通过验收。
8. 无论结果如何，恢复本机原22配置并核对哈希，停止生产临时unit、核对443不再监听，清理仅本次自动回退timer。记录完整结果。原计划STOP、请求计数和两业务集合计数必须不变。若管理连接失联，不重复启动试验；依赖已安装8/10分钟自动退出，待连接恢复后只读核验。
