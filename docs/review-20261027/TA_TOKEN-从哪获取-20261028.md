# `TA_TOKEN` 从哪来

> 结论先说：**没有现成的 `TA_TOKEN` 存在某个配置里**。它是我在执行单里给「运维用 Bearer Token」起的占位名，
> 真实身份是 **登录接口签发的 JWT**，有效期 **1 小时**。

## 1. 它到底是什么（已核对代码）

```
app/routers/scheduler.py:155   @router.get("/jobs")
                               user: dict = Depends(get_current_user)
app/routers/auth_db.py:70      get_current_user 支持三种：京东云 Basic / JWT Bearer / Session Cookie
app/routers/auth_db.py:340     token = AuthService.create_access_token(sub=user.username, session_id=...)
app/router_registry.py:85      auth 路由挂载在 /api/auth
```

- 走的是 **JWT Bearer**（`Authorization: Bearer <token>`），不是 API Key。
- token 里带 `session_id`，服务端还会去 MongoDB `sessions` 集合校验；**1 小时 TTL**（refresh 7 天）。
- 所以拿不到一个「长期有效」的静态 token，也不该造一个。

生产账号情况（只读核实）：`users` 集合 **1 条**，`is_admin=true`，`is_active`。代码里**没有注册接口**，不能新建账号。

## 2. 三种拿法，按推荐顺序

### A. King 给凭据、接手方自己登录（推荐）

King 在 devbox 上通过安全编辑方式创建 `/home/ubuntu/.ta_ops_cred`：第一行用户名，第二行密码，
文件仅当前用户可读写（权限 600）。不要把密码写进 shell 命令、聊天或 git。

使用已测试的取证工具。它将凭据通过 SSH stdin 交给生产容器，在容器内完成正常登录和调度查询，
只返回目标任务状态，不输出或保存密码、JWT、refresh token，也不把它们放进命令行：

```bash
python3 -B deploy/query_quote_guard_jobs.py \
  --credentials-file /home/ubuntu/.ta_ops_cred \
  --ssh-config /home/ubuntu/.ssh/osaka-migration-20261016-hKbxOKhx/config \
  --host osaka-migration \
  --container ta-live-088a60b962bf-backend-1 \
  --output /home/ubuntu/quote-guard-releases/production-20261028/jobs-before.json
```

输出文件必须尚不存在，权限自动设为 600。部署后使用新的 `jobs-after.json` 输出路径。
如提供现成 JWT 文件，改用 `--token-file <权限600的文件>`；不会调用登录接口。
缺失 ingestion 任务仍须结合封印配置关闭证据判断；工具退出码 0 不单独批准部署。

旧示例把宿主机 `/tmp/curlrc` 直接交给容器内 curl 读取，路径不可见；另有字符串拼 JSON、
在 devbox 上直接 `sudo docker exec` 等问题，已移除，不应复制执行。

### B. King 自己登录浏览器，将 token 存入本机受限文件

登录前端 → 开发者工具 → `localStorage` 里取 `access_token`（或直接取 Cookie）。
将 token 安全保存为 devbox 上权限 600 的文件，只提供路径；不要通过聊天或文档传递。1 小时后需要重新获取。

### C. 只在部署时由 King 跑那两条命令

部署前后均需要经鉴权取得当前任务状态；以 v11 的实际验收流程为准，v9 已作废。
King 可以自己在部署窗口内跑，把**输出**（不含 token）交给接手方。这样谁都不用把凭据交出去，代价是 King 必须在线。

## 3. 注意事项

- **登录会建立 access/refresh 会话并记录审计**。这是正常认证行为，不能声称“完全没有写入”；工具不修改行情、交易记录或调度偏好。
- 拿不到的后果：**必须停**。不要用「启动日志里有 `⏸️ ... 已添加但暂停`」替代——
  `app/main.py` 在打印暂停之后还会恢复持久化偏好，日志证明不了最终状态（这条已被评审否掉过一次）。
- 不要走的路：用 `settings.JWT_SECRET` 自己签一个。那等于绕过认证，而且还要往 `sessions` 写记录，评审不会接受。
- 不要在任何文档、提交、截图中出现 token 或密码明文。

## 4. 执行单里怎么改

v9 是历史草案，不再作为执行依据。当前工具直接读取受限文件，无需导出 `TA_TOKEN` 环境变量。
