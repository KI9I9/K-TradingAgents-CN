## 6. 回滚（竞态已消除）

**原则：重建之前先证明「重启后不会自动恢复写入」，否则保持实例停止。**

```bash
# R0-a 证据：持久化偏好
cat $D/prefs-before.json      # 逐条看 enabled
```
- 若两条都 `enabled=false`（或不存在）→ 可直接走 R1。
- 若任一 `enabled=true`：
  1. 实例**仍在运行**时，先用 API `pause` 并确认 `paused=true`；
  2. 重新读 `scheduler_preferences` 确认已落库；
  3. 再做 R1/R2。**不允许**「先重建、再靠 pause 救」。

```bash
# R1 还原 4 个挂载源
sudo cp $B/config.py $SRC_CFG; sudo cp $B/provider-akshare.py $SRC_PROV
sudo cp $B/akshare_sync_service.py $SRC_SYNC; sudo cp $B/stock_sync.py $SRC_STK

# R2 去掉新挂载重建（必须在 R1 之后）
sudo docker compose ... -f 原链 only ... up -d --no-deps --force-recreate backend

# R3 复验：挂载 21、6 个文件哈希回到 $B/SHA256SUMS、任务仍 paused
# R4 前端回滚
sudo docker compose ... -f $D/compose.paper-guard.json up -d --no-deps --force-recreate frontend
```

**故障分支（backend 起不来 / API 不通）**：`docker stop $C` → 确认 `docker inspect -f '{{.State.Running}}' $C` 为 false
（不要用宿主机 `ss` 推断容器内进程）→ 走 R1/R2 → 重建后**再查一次**偏好与 `paused`；仍为 true 则立即停止实例并上报，不自行改库。
