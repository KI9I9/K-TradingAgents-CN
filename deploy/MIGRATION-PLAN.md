# 本地 WSL 到 Ubuntu 服务器迁移执行单

## 当前阶段：本地准备完成，等待目标服务器信息

本地工程：`/home/marvin/project/K-TradingAgents-CN`。
四个服务：frontend、backend、mongodb、redis。
当前全部镜像为 Linux amd64；远端若为 ARM64，必须重建相应架构镜像，不直接复用当前镜像。
迁移应使用 `deploy/ubuntu-migration-20261014` 分支，包含调度修复、助手提示修复与部署工具；不要只克隆旧的默认分支。

## 接入信息

需要 SSH 主机别名或地址、端口、用户名，以及可用的密钥登录方式。不在聊天中提交密码、私钥或 API Key。
连接后先只读核对 Ubuntu 版本、CPU 架构、内存、磁盘余量、Docker/Compose、已有服务及端口占用。
首轮保持前端仅监听服务器 `127.0.0.1:8088`，通过 SSH 隧道访问。公网域名、HTTPS 和开放端口另行确认。

## 第一步：代码与可回退版本

1. 核对本地修改、测试及敏感文件排除规则，再整理 Git 提交并推送用户 fork；`.env`、备份及数据卷内容不进入 Git。
2. 首次迁移优先复用已验收镜像（目标为 amd64 时），避免重新解析未完全锁定的依赖造成差异。可用 `docker save` 导出前后端和数据库镜像，经 SSH 传输后 `docker load`。
3. 镜像归档另计算 SHA-256；目标端对比校验和及镜像标识。

## 第二步：正式备份

目标服务器准备好、用户确认切换窗口后，检查运行中任务并安排应用短暂停写。
备份工具默认只读；显式执行参数才会停服：

```bash
cd /home/marvin/project/K-TradingAgents-CN
python3 deploy/migration_backup.py --inventory-out /tmp/k-tradingagents-inventory.json
# 下列目录需为新的、尚不存在的备份目录。
python3 deploy/migration_backup.py --execute-backup /home/marvin/backups/k-tradingagents/NEW-MIGRATION-BACKUP
```

备份包含：

- MongoDB 逻辑归档（包括配置、用户、历史行情、会话与调度偏好）。
- `.env`、实际工作区源码归档和版本／镜像清单。
- 七个应用数据卷：app_data、app_logs、app_runtime、app_results、app_reports、app_uploads、app_config。
- Redis 数据卷冷备份，留作回退；目标端是否恢复另行评估，通常使用新缓存并重新登录，避免带入旧锁和队列。
- 校验和清单和 COMPLETE 完成标记；没有完成标记的备份不得用于正式迁移。

工具停止本项目的前端、后端和 Redis；MongoDB 保持运行供逻辑导出。失败也会尝试恢复原先运行的本地服务。本地原数据卷不会被删除。
备份包含密钥，仅通过 SSH/SFTP 传输到限制权限的目录。

## 第三步：服务器恢复（接入后按真实环境执行）

1. 校验收到的备份校验和及压缩流；源码解包前检查路径，拒绝越界、异常链接。
2. 选择独立项目目录；若发现同名现有项目或数据卷，先报告冲突，不覆盖。
3. 恢复源码与 `.env`，将 `.env` 权限设为 600；核对本地地址、代理及服务路径，记录确有必要的服务器差异。
4. 导入已验证镜像，创建但不启动应用容器，确认目标数据卷为空。
5. 向对应空数据卷恢复七个应用归档，保留 UID/GID 与权限；不要直接覆盖正在运行的卷。
6. 只启动 MongoDB，逻辑恢复应用数据库（实际数据库名由配置确认），不盲目覆盖服务器的 admin 数据库。
7. 保存原调度偏好副本，再在服务器数据库中暂时关闭全部定时任务；本地原偏好不变。默认使用新的 Redis，旧缓存留在备份中。
8. 启动后端和前端，通过 SSH 隧道验收。程序原有的启动初始化可能访问行情接口，定时任务暂停并不禁止所有启动初始化。

## 第四步：验收与切换

- 配置、厂家、用户等集合：记录数和内容指纹对比，确有服务器差异时逐项说明。
- 历史行情：按数据源／周期对比记录数量、最早和最晚日期。
- 应用文件：卷归档与关键文件完整性；验证报告下载、会话读取、上传文件访问。
- 页面登录、助手模型选择、能力索引、数据源连接和一次实际分析。
- 核对付费调用模型、数据源权限及费用后进行真实分析验收。
- 确认切换后，关闭本地自动调度，再在服务器恢复已保存的用户开关，避免双重执行。
- 本地实例及完整备份保留作开发和回退，数据不自动双向同步。
